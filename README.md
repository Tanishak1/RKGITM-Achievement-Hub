# RKGITM Achievement Hub

A digital platform for showcasing verified student achievements, projects, research and campus communities.

## MVP
- Public institutional showcase
- Student achievement submission flow
- Faculty/admin verification workflow
- Verified student profiles and QR verification (planned)
- LinkedIn-ready content workflow (planned; human approval before publishing)

## Stack
- Frontend: Next.js + TypeScript
- Backend: Java + Spring Boot
- Database: PostgreSQL (integration in progress)

## Run frontend
```bash
cd frontend
npm install
npm run dev
```

## Run backend
```bash
cd backend
mvn spring-boot:run
```

> MVP under active development. Public content and statistics should only use verified institutional data.
